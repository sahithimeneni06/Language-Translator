# Language Translator

A beautiful **AI-powered multilingual language translator** built with **Streamlit + Transformers (mBART-50)**.  

Supports **50+ languages**, including:

✅ English  
✅ Telugu  
✅ Hindi  
✅ Tamil  
✅ French  
✅ German  
✅ Arabic  
✅ Bengali  
✅ And many more…

---

## ✨ Features

- 🌍 Translate between **50+ languages**
- ✨ Transparent **Glassmorphism Text Area**
- 🎴 **Animated Output Card**
- ⚡ Powered by **Facebook's mBART-50 Model**
- 🖥 Works on **CPU & GPU**
- ☁ Ready for **Streamlit Cloud Deployment**

---

## 🛠 Tech Stack

- **Frontend:** Streamlit  
- **Model:** mBART-50 (Transformers)  
- **Backend:** PyTorch  
- **Styling:** Custom CSS 
- **Tokenization:** SentencePiece

## ✅ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/sahithimeneni06/language-translator.git
cd galaxy-language-translator
```
2️⃣ Create Virtual Environment (Recommended)

```bash
python -m venv venv
venv\Scripts\activate    # Windows
```

3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

4️⃣ Add Background Image

```bash
image.png
```

5️⃣ Run the App
```bash
streamlit run app.py
```
